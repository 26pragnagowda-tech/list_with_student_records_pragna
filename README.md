Student Records Management System

Description

This project is a Python program that stores student names and marks using lists. It allows users to search for students, sort records according to marks, and identify the highest and lowest scores.

Objectives

- Understand Python lists.
- Learn how to add and access list elements.
- Practice searching and sorting.
- Use built-in functions such as "max()", "min()", and "sorted()".

Requirements

- Python 3
- VS Code or IDLE

Features

- Stores student names and marks.
- Searches for a student by name.
- Sorts students from highest to lowest marks.
- Displays the highest and lowest scores.
- Identifies the top-performing student.

How to Run

1. Open the project in VS Code.
2. Open "student_records.py".
3. Run the program.
4. Enter the number of students, their names, and marks.
5. View the student records and results.

Concepts Used

Python lists, loops, conditional statements, user input, list methods, "zip()", "max()", "min()", and "sorted()".

Conclusion

This project helps develop practical Python programming skills by demonstrating how lists can be used to store, search, sort, and analyze student records.
